# 应用管控 Demo

独立Android项目，不修改幻境；本机Root，支持抖音及用户勾选的第三方应用。

管控名单按用户表达：勾选即加入管理，不自动停用。每个应用分别恢复使用/停用/打开；停用可选择手动恢复或秒/分钟/小时倒计时。移出名单前恢复本Demo的暂停。一键恢复全部仅恢复本Demo接管的应用。

原生Java11 Views、min26/target31/compile31，不引入运行时库。Root通过su -c调用固定pm suspend/unsuspend和am force-stop，参数严格校验、限定当前Android用户、串行后台执行、超时及错误反馈；暂停成功后停止进程。拒绝接管已被外部暂停的应用；验证系统实际状态，不将Shell返回0直接视作成功。

系统AlarmClock精确任务+私有持久化。先保存恢复意图/安排闹钟再暂停；到期自动解除，后台进程被普通回收不影响AlarmManager；开机、更新、系统时间变更后恢复安排。同一次开机用单调时钟；重启后用保存的墙钟到期时间。失败保留所有权及恢复任务、显示错误并重试。Android强行停止/撤销闹钟权限/卸载会破坏系统任务，Demo说明中明确恢复步骤，不宣称无法绕过。

自保护：只列第三方应用，排除自身、当前桌面及已知Root管理器/系统配置组件。非选中应用不执行操作。所有Receiver除系统开机/时间变更入口外均不导出，闹钟使用不可变显式PendingIntent。无互联网权限。

UI深色青蓝工具风：Root/闹钟权限状态；管控名单与应用选择页；搜索名称/包名；每应用独立计时状态，恢复全部按钮；48dp触摸目标与中文contentDescription。

验证：纯Java状态机测试包含选中隔离、无Root/写盘/调度失败、超时恢复、外部暂停拒绝、重新计时、重启/改时钟、防命令注入、移出名单恢复。MuMu若已装抖音则实测抖音，否则先用独立无权限测试App验证，抖音单独注明未安装；不自行下载安装第三方抖音APK。实际测试结束恢复所有本次测试目标。
